# Listening Practice — Online shopping

Designed by Abhi-Uyen.

## Upload to GitHub Pages

1. Upload `index.html` and the complete `assets` folder to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch containing the files and **/(root)**, then save.

Keep `assets/listening.mp3` at this exact relative path. No installation or backend is required.

## Questions and answers

The four questions have been rewritten as complete comprehension questions and numbered 1–4. Every question uses the same options: Speaker A, B, C and D. The transcript and supplied MP3 are unchanged.

1. Product and brand variety: D.
2. Comparing prices and finding the best deal: B.
3. Delivery to the speaker’s floor and apartment door: A.
4. Saving time because of a busy work schedule: C.

Question 3 asks about details explicitly stated only by A, avoiding the overlap caused by a general question about delivery. Answers are grounded in the supplied transcript, with evidence and Vietnamese explanations in the app.

## Learning modes

- Listening Test: all four questions displayed together (2×2 on desktop, stacked on mobile); transcript hidden; submit after all four choices.
- Transcript: complete English paragraphs, Vietnamese off by default, manual highlighting.
- Drilling: transcript and one question in two columns on desktop; evidence and explanation after checking.
- Reset All: clears choices, highlights, Vietnamese display and playback state.
